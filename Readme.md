# SubwaySurfers API Web

A simple web interface for interacting with the internal API used by the Subway Surfers and Subway Surfers City games.  
This project provides a frontend that allows you to send requests using your own `identityToken` without exposing data to any external server. \
Everything runs locally in your browser.

https://github.com/HerrErde/SubwaySurfers-Api
https://github.com/HerrErde/SubwaySurfersCity-API

---

## Features

- Browse and call internal Subway Surfers and Subway Surfer City API endpoints
- Local-only: no data is sent anywhere except to the official game servers (and a cors proxy)
